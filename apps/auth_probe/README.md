# MAX Auth Probe

Небольшое Flutter-приложение для проверки реальной работоспособности пакета `maxai_protocol` на Windows.

## Первая версия: WebSocket + QR

Сценарий проверки:

1. Открыть WebSocket `wss://api.oneme.ru/websocket`.
2. Выполнить `SESSION_INIT` для WEB device.
3. Запросить QR через `GET_QR` (opcode 288).
4. Показать QR-код в окне приложения.
5. Периодически проверять `GET_QR_STATUS` (opcode 289).
6. После подтверждения выполнить `LOGIN_BY_QR` (opcode 291).
7. Полученный токен передать в `LOGIN` (opcode 19).
8. Если сервер выставил соответствующие флаги, выполнить `LOGIN2` (opcode 8).
9. Показать сводку результата без отображения токена.

Токен не сохраняется на диск. QR track ID и токены не выводятся в журнал.

## Запуск на Windows

Требуется установленный Flutter SDK с поддержкой Windows Desktop.

Из каталога приложения:

```powershell
cd apps/auth_probe
flutter create . --platforms=windows
flutter pub get
flutter analyze
flutter run -d windows
```

Для последующих запусков достаточно:

```powershell
flutter run -d windows
```

Пакет `maxai_protocol` подключается локально через path dependency. Отдельная публикация пакета не требуется.

## Ограничения текущего стенда

- Проверяется только WebSocket + QR сценарий.
- TCP + TLS и SMS будут добавлены отдельным этапом.
- Нет постоянного хранения токена или сессии.
- Нет автоматического переподключения.
- Совместимость с текущим сервером MAX не гарантирована: протокол неофициальный и может измениться.
- Для первой проверки рекомендуется отдельный тестовый аккаунт.

## Безопасность

Не публикуйте скриншоты с активным QR-кодом. QR-код является средством входа в аккаунт. Не передавайте журнал или диагностические данные третьим лицам без проверки на чувствительные сведения.
