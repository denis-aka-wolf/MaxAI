# MaxAI

Самостоятельный MAX-клиент и AI-ассистент на Dart + Flutter для Windows.

## Статус разработки

Проект находится на этапе проверки протокола MAX и завершения протокольного ядра. Внутренний API MAX не является публичной стабильной спецификацией, поэтому совместимость каждой операции подтверждается отдельно.

## Структура проекта

- [Документация проекта](docs/README.md) — каталог технической документации.
- [Спецификация протокола MAX](docs/MAX_Protocol_Specification.md) — исследование структуры протокола.
- [Дорожная карта](docs/ROADMAP.md) — этапы и план разработки.
- [Read-only API Probe](docs/READ_ONLY_API_PROBE.md) — реализованные операции чтения и порядок их проверки.
- [Настройка TLS-сертификатов Windows](docs/TLS_CERTIFICATE_SETUP.md) — проверка и установка сертификатов для TCP/TLS.
- `packages/maxai_protocol/` — самостоятельная Dart-библиотека протокола MAX.
- `apps/auth_probe/` — отдельное Windows-приложение для лабораторной проверки авторизации, TLS и API. Это тестовый инструмент, а не основное приложение MaxAI.

## Реализованные возможности протокольного ядра

- TCP/TLS-транспорт для mobile-подключения и WebSocket-транспорт для web-подключения.
- Mobile/web `SESSION_INIT` и Heartbeat.
- QR-авторизация через WebSocket.
- SMS-авторизация через TCP/TLS и обработка 2FA.
- `LOGIN` / `LOGIN2`, восстановление сессии и локальный Logout.
- Защищённое локальное хранение токена и device ID через Windows DPAPI.
- Начальный набор read-only API: снимки профиля и контактов из LOGIN/LOGIN2, CONTACT_INFO (32), CHATS_LIST (53), CHAT_INFO (48), CHAT_MEMBERS (59), CHAT_HISTORY (49) и MSG_GET (71).
- Диагностика и раздельные действия проверки/установки TLS-сертификатов в `auth_probe`.

Реализация read-only API и схемы payload основаны на исследовании PyMax. Живую проверку каждого метода на сервере MAX ещё необходимо завершить. Наличие реализации и успешные unit-тесты сами по себе не доказывают серверную совместимость.

## Запуск auth_probe на Windows

Из корня репозитория:

```powershell
cd apps/auth_probe
flutter pub get
flutter analyze
flutter test
flutter run -d windows
```

Для сборки Windows-проекта используйте сгенерированные платформенные файлы репозитория. Команда `flutter create .` нужна только если Windows runner отсутствует, а не для каждого запуска.

## Проверка протокольного пакета

cd packages/maxai_protocol

## Принципы проекта

- `auth_probe` остаётся отдельной лабораторией и не подменяет основное приложение MaxAI.
- Секреты и персональные данные не должны попадать в исходники и диагностические журналы.
- TLS-проверка не отключается и не обходится.
- Неизвестные детали протокола явно отмечаются как требующие проверки.
- Операции изменения данных не добавляются в read-only API.
- Групповые чаты исключаются из AI-обработки согласно принятому проектному требованию.
- Автоматическая отправка сообщений выключена по умолчанию и требует явного разрешения.
