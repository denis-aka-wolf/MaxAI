# MaxAI Roadmap

> Главный принцип: сначала исследуем и проверяем протокол MAX в отдельном приложении `apps/auth_probe`, затем завершаем библиотеку `maxai_protocol` и только после этого начинаем полноценную разработку MaxAI.

Статусы в этом документе отражают состояние плана, а не автоматически подтверждённую работоспособность. Задача считается завершённой после реализации, проверки и обновления документации.

- [x] Добавить диагностику Russian Trusted Root CA.
- [x] Реализовать отдельные проверки и действия установки Root CA и Intermediate CA.
- [x] Реализовать проверку отпечатка корневого сертификата.

- [x] Проверять подпись, цепочку доверия, назначение CA и сроки действия сертификатов.
- [x] Загружать сертификаты только из проверенных источников.
- [x] Запрашивать явное согласие пользователя перед установкой.
- [x] Устанавливать Root CA в `CurrentUser\\Root`, Intermediate CA в `CurrentUser\\CA`.
- [x] Проверять результат установки и повторно выполнять TLS-подключение.

- [ ] Проверить просроченные, подменённые и недействительные сертификаты.

## Критерии готовности этапов

- Реализация подтверждена тестами и, где необходим реальный сервер, практической проверкой.
- Неизвестные особенности протокола или API не выдаются за подтверждённые.
- Секреты и персональные данные не попадают в диагностические журналы.
- Ошибки и неопределённые результаты обрабатываются явно.
- Документация соответствует фактическому поведению реализации.

## Архитектурные принципы

1. `auth_probe` остаётся отдельным тестовым приложением.
2. `maxai_protocol` не зависит от Flutter UI и бизнес-логики CRM.
3. Интеграция Битрикс24 реализуется отдельным модулем, не смешивается с MAX transport/API.
4. Битрикс24 является источником CRM-контактов, задач и плановых дат коммуникаций; MAX является источником фактов переписки и статусов сообщений.
5. AI анализирует объединённый контекст и предлагает действия, но не подменяет факты CRM или MAX своими предположениями.
6. Отправка сообщений и изменение CRM-данных выполняются контролируемо, с подтверждением пользователя и проверкой результата.
