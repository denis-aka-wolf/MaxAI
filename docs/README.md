# Документация MaxAI

Основной язык документации проекта — русский. Русскоязычные документы являются первоисточниками. Английские переводы хранятся в отдельных Markdown-файлах с префиксом `ENG_`.

## Языковое соглашение

- **RU по умолчанию:** файл без префикса `ENG_` содержит русскую версию.
- **ENG:** английский перевод имеет то же базовое имя с префиксом `ENG_`.
- Например, `ROADMAP.md` — русский оригинал, `ENG_ROADMAP.md` — его английский перевод.
- Новые документы создаются сразу на двух языках.
- При изменении русского оригинала соответствующий английский перевод проверяется и обновляется в том же изменении.
- Английская версия должна сохранять структуру, технический смысл, статусы, примеры, таблицы и предупреждения русского оригинала.
- Имена API, opcode, классов, методов, переменных, полей протокола, команд и путей файлов не переводятся.
- Если перевод ещё не синхронизирован, это явно указывается в обоих документах.

## Порядок обновления

1. Внести и проверить изменения в русскоязычном документе.
2. Обновить английский перевод, сохранив соответствие разделов и технических деталей.
3. Проверить ссылки между документами и актуальность таблицы выше.
4. В одном pull request/коммите включать обе языковые версии, если изменение затрагивает содержание документации.

Русская версия имеет приоритет при разрешении расхождений. Английский перевод не должен вводить новые технические утверждения, отсутствующие в оригинале.
